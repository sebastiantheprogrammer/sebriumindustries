# Updating the project collection

Edit `src/data/projects.ts` and add an entry to `PROJECTS`. Give it a unique `id`, a display `name`, an existing `category`, and a short `description`. Optional fields: `logo` (a public asset path), `href` (a confirmed public destination), and `linkLabel` (defaults to “View project”). Counts and filters update automatically. Entries without a link display “In development”. Build and deploy after saving to publish changes; this is a source-managed collection, not a public editing form.
